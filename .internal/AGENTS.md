The .internal folder contains the generator code for the tool specific plugin definitions. 

The plugins and tool ecosystem is constantly evolving and new capabilities are added frequently. 

When making changes, **always** refer to the vendor reference documentation before doing changes. 
After checking vendor reference, make only the changes you are asked to, but recommend possible additions or improvements to the setup. 

Never directly touch the files outside the `.internal` folder.  The skills and agents are synced in from the development source, the various manifest files are generated by the implementation here in .internal.
